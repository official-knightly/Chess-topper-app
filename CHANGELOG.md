# Changelog

## 1.0.0 - Chessist Local desktop foundation
- Electron-first desktop application with a sandboxed React renderer.
- Lichess OAuth PKCE, encrypted token storage, Board API play and active-game monitoring.
- Berserk WASM analysis and local engine games.
- Chess.com published public-data lookup and official external play handoff.
- Local PGN library, review, puzzle, opening explorer and performance tools.
- Desktop CI and Windows, macOS and Linux packaging workflows.
- Fair-play lock prevents engine searches during active games involving the connected Lichess account.
